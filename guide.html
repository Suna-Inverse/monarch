Shared scripts

InDesign scripts to download

Handy scripts shared for Monarch members. To use one: in InDesign choose Window › Utilities › Scripts, right-click the User folder and choose Reveal in Finder, then put the downloaded script in that folder. It shows up in the Scripts panel straight away; double-click it to run.
